What was true when.

Cryptomnia is the memory layer for crypto. It keeps every risk score, attribution, and claim as a time-stamped Event Object so you can prove what was known at the moment a decision was made.

See the idea Read the whitepaper Get in touch

Why this matters

On-chain data is permanent. The meaning of that data is not. Risk scores change. Entity attributions are revised. Sanctions lists are updated. Audit conclusions are overturned.

Most tools only show the current view. Cryptomnia stores every version with its source and timestamp, so you can answer the question that actually matters in compliance, research, and risk: what was true when the decision was made?

Time-aware risk

Store successive risk scores for an address. Later, retrieve the exact score that was active on the day a transaction was approved. A visual timeline shows how the score evolved by source.

Auditable forgetting

When a source is discredited, mark it forgotten. The removal itself becomes a permanent, queryable record. Nothing is silently overwritten.

Provenance built in

Every assessment carries who, when, and which source. Supporting evidence files can be attached to any observation and retrieved later with the claim.

Automated feed

A scheduled process can continuously write new Observations from external or heuristic sources. Timeline, as-of queries, and forgetting continue to work unchanged.

Built on Pod-OS

Cryptomnia runs on Pod-OS, a time-aware multigraph database. Facts are stored as Event Objects with full spacetime context. Previous versions are never lost. Forgetting is auditable.

A reference Streamlit prototype demonstrates the full flow: ingest Observations, view them on an interactive timeline, run as-of queries, mark claims forgotten, and attach evidence files — all against a live Pod-OS ENM.

Example sequence

What a live query looks like:

risk 0xdeadbeef 92 chainalysis # 10 Oct · high mixer exposure
risk 0xdeadbeef 45 internal # 14 Oct · cleared after review
history 0xdeadbeef
→ risk-a1b2 · score 92 · source chainalysis · 2026-10-10
→ risk-c3d4 · score 45 · source internal · 2026-10-14
as-of 0xdeadbeef 2026-10-16 # transfer approved
→ risk-c3d4 · score 45 · source internal · valid at approval
forget risk-a1b2
→ Auditable forget recorded. Original assessment marked forgotten. Record remains queryable.
